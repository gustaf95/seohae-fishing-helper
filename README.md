# 🎣 해안 낚시 도우미 (서해)

서해 방파제·원투(해안) 낚시를 위한 **주간 날씨 · 물때 · 주변 포인트 추천** 웹앱입니다.
설치 없이 `index.html` 하나로 동작하며, 데이터는 브라우저(localStorage)에 저장됩니다.

## 주요 기능

- **📍 낚시 포인트 등록** — 서해 인기 포인트 프리셋 / 좌표 직접 입력 / 현재 위치(GPS)
- **🌤️ 주간 날씨 (7일)** — 기온·바람(풍향)·강수확률·**파고**, 실시간 데이터 (Open‑Meteo, API 키 불필요)
- **🎯 날짜별 낚시 좋은 시간대** — 각 날짜에 몇 시~몇 시가 좋은지 표시
- **🌊 물때 (쉬운 표현)** — "물 들어오는 시간(들물) = 낚시 좋은 때"로 안내, 물때(사리/조금)·물살 세기·달 위상
  - 날씨에서 **날짜를 누르면** 그날 물때가 표시됩니다
- **🧭 주변 추천 포인트** — 등록 지점 기준 거리순 + 제철 어종
- **⚠️ 서해 갯벌 안전 안내** — 밀물 위험 경고

## 사용법

브라우저에서 `index.html`을 열면 됩니다. 현재 위치(GPS) 기능을 쓰려면 로컬 서버로 여는 걸 권장합니다.

```bash
python -m http.server 5500
# 브라우저에서 http://127.0.0.1:5500 접속
```

## 데이터 출처 / 참고

- 날씨·파고: [Open‑Meteo](https://open-meteo.com/) (실시간)
- 물때·달 위상: 자체 계산 (음력/삭망 기반)
- **만조·간조 시각은 달 위상 기반 근사값**입니다. 분 단위 정확한 조석은 [국립해양조사원 바다누리](https://www.khoa.go.kr/)에서 확인하세요.
