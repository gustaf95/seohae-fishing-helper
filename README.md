# 🎣 해안 낚시 도우미 (서해)

> 배 안 타고 **해안(방파제·원투)** 에서 낚시하는 사람을 위한 웹앱.
> 낚시 포인트를 등록하면 **주간 날씨·파고**, **물때(낚시 좋은 시간)**, **주변 추천 포인트**를 한눈에 보여주고,
> **친구와 같은 포인트 목록을 실시간으로 함께 관리**할 수 있습니다.

서해 시흥 오이도·시화나래 일대를 기준으로 만들었지만, 좌표만 넣으면 어느 해안이든 동작합니다.

- **실행 방식**: 설치·빌드 없이 `index.html` 하나로 동작 (바닐라 HTML/CSS/JS)
- **실시간 공유**: Firebase Realtime Database (방 코드로 여러 명 동기화)
- **실시간 데이터**: Open‑Meteo (날씨·파고, API 키 불필요)

## 주요 기능

### 📍 낚시 포인트 등록 (실시간 공유)
- 서해 인기 포인트 **프리셋 9곳** 빠른 선택 (오이도·시화나래·대부도·탄도항·전곡항·제부도·궁평항·소래·을왕리)
- 좌표(위도/경도) 직접 입력 또는 **현재 위치(GPS)** 로 등록
- 등록한 포인트는 **방 코드로 묶인 사람들과 실시간 공유**되며, 누가 추가했는지(별명) 함께 표시

### 🌤️ 주간 날씨 · 파고 (7일)
- 기온(최고/최저), **바람(풍속·풍향)**, 강수확률, **파고(파도 높이)** 를 하루 단위로 표시
- 바람·파고·강수를 종합한 **낚시 적합도** 뱃지 — `좋음 / 보통 / 주의`
- 날짜별로 **낚시 좋은 시간대(🎯 몇 시~몇 시)** 를 바로 표시

### 🌊 물때 · 낚시 좋은 시간
- "만조/간조" 같은 어려운 말 대신 **"물 들어오는 시간(들물) = 낚시 좋은 때"** 로 직관적으로 안내
- 날짜·달 위상으로 **물때(사리/조금)**, **물살 세기(%)**, **달 모양**을 계산
- **날씨 카드의 날짜를 누르면** 그날의 물때가 아래에 표시됨
- 정확한 조석은 **국립해양조사원** 링크로 바로 확인

### 🧭 주변 추천 포인트
- 선택한 포인트 기준 **거리순**으로 주변 낚시터 추천
- 그 계절의 **제철 어종** 표시 (여름: 붕장어·보리멸·우럭 / 가을: 주꾸미·갑오징어·망둥어 등)
- 버튼 한 번으로 내 포인트에 **추가**, 구글 지도 바로가기

### ⚠️ 서해 갯벌 안전 안내
- 밀물 위험(갯골로 물이 차오름)에 대한 경고를 항상 노출

## 사용 방법

1. **공유 방 만들기 / 입장**
   - 별명(예: `지훈`)과 **방 코드**(예: `우리낚시팀2026`)를 입력하고 **방 입장 / 만들기**
   - 처음이면 아무 코드나 정해서 만들면 됩니다. 그 코드를 친구에게 알려주세요.
2. **친구 초대**
   - 친구는 **같은 방 코드**로 입장하면 같은 포인트 목록을 함께 봅니다.
   - 방 코드 옆 **📋 복사** 버튼으로 코드를 복사해 전달할 수 있어요.
3. **포인트 추가**
   - `＋ 포인트 추가` → 프리셋 선택 / 좌표 입력 / 현재 위치 → **추가**
   - 추가·삭제가 **친구 화면에도 즉시 반영**됩니다.
4. **날씨·물때 확인**
   - 주간 날씨에서 날짜를 누르면 그날의 물때·낚시 좋은 시간이 아래에 나옵니다.

> 데이터는 **방 코드별로** 저장됩니다. 방 코드를 아는 사람만 그 목록을 봅니다.

## 실시간 공유는 어떻게 동작하나요

```
[내 브라우저]  ─┐
                ├─▶  Firebase Realtime Database  ─┐
[친구 브라우저] ─┘        rooms/{방코드}/points     │
       ▲                                           │
       └──────── 변경사항 실시간 푸시 ◀────────────┘
```

- 포인트는 Firebase의 `rooms/{방코드}/points` 경로에 저장됩니다.
- 각 브라우저는 이 경로를 **구독(onValue)** 하고 있어서, 누군가 추가/삭제하면 **새로고침 없이** 모두의 화면이 갱신됩니다.
- 날씨·물때는 공유 대상이 아니라, 각자 브라우저에서 실시간 계산/조회합니다.

**보안 모델**: 데이터베이스 규칙이 공개(`.read/.write: true`)라, **방 코드를 아는 사람은 그 방의 목록을 읽고 쓸 수 있습니다.** 낚시 포인트 정도의 비민감 정보를 소수의 친구끼리 공유하는 용도로 적합합니다. 남들이 추측하기 어려운 방 코드를 쓰세요.

## 로컬에서 실행하기

`index.html` 하나면 되지만, **GPS(현재 위치)** 기능과 브라우저 보안 정책 때문에 **로컬 서버로 여는 것을 권장**합니다.

```bash
# 저장소 폴더에서
python -m http.server 5500
```
그다음 브라우저에서 접속:
```
http://127.0.0.1:5500
```

> 파일을 더블클릭해 `file://` 로 열어도 대부분 동작하지만, 일부 브라우저에서 GPS·모듈 로딩이 막힐 수 있습니다.

## 인터넷에 배포하기

정적 파일 하나라 어디에 올려도 됩니다. 대표적인 방법:

| 방법 | 코드 수정 시 | 준비물 |
|------|--------------|--------|
| **Netlify Drop** (드래그) | 매번 수동 업로드 | 없음 (즉시) |
| **Netlify / Vercel + GitHub 연결** | `git push` 하면 **자동 배포** | 무료 계정 1회 연결 |
| **GitHub Pages** | `git push` 하면 자동 배포 | 저장소 Settings → Pages |

**GitHub Pages 사용 시 참고**: 순수 정적 사이트이므로 저장소 루트에 빈 파일 `.nojekyll` 을 두어 Jekyll 빌드를 건너뛰게 하는 것이 안전합니다(이 저장소엔 포함돼 있음).

**자동 배포를 원하면** GitHub 저장소를 Netlify/Vercel에 연결하는 방식을 추천합니다. 한 번 연결하면 이후 push할 때마다 사이트가 자동 갱신됩니다.

## 내 Firebase로 바꾸기 (포크용)

이 저장소를 포크해서 **본인 Firebase 프로젝트**로 쓰려면:

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 생성 (무료 Spark 요금제로 충분)
2. **빌드 → Realtime Database** 생성 (위치: 싱가포르 권장) → 규칙을 아래로 설정 후 게시
   ```json
   { "rules": { ".read": true, ".write": true } }
   ```
3. **프로젝트 설정 → 내 앱 → 웹(`</>`)** 등록 후 나오는 `firebaseConfig` 복사
4. `index.html` 안의 `firebaseConfig` 객체를 본인 값으로 교체
   ```js
   const firebaseConfig = {
     apiKey: "…",
     authDomain: "…",
     databaseURL: "https://…-default-rtdb.…firebasedatabase.app",
     projectId: "…",
     storageBucket: "…",
     messagingSenderId: "…",
     appId: "…"
   };
   ```

> 참고: 웹 앱의 `firebaseConfig`(특히 `apiKey`)는 **비밀키가 아니라 공개돼도 되는 식별자**입니다. 클라이언트 코드에 넣는 것이 정상이며, 접근 제어는 데이터베이스 **보안 규칙**으로 합니다. (서비스 계정 키 같은 진짜 비밀키는 절대 코드에 넣지 마세요.)

## 물때 계산 방식과 주의사항

- 물때·달 위상은 **삭망 주기(약 29.53일)** 기준으로 음력일과 달 위상을 계산해 구합니다.
- **물살 세기**는 스프링–니프(사리–조금) 주기를 근사해 백분율로 표시합니다. (사리 100% ↔ 조금 최저)
- **들물/만조 시각**은 달의 남중 시각 + 지역 고조간격(인천 근사 ≈ 4시간)으로 **추정한 근사값**입니다.

> ⚠️ 표시되는 만조·들물 시각은 **근사값**으로, 실제와 **10~30분 이상 차이**날 수 있습니다.
> 안전이 걸린 계획(갯벌 진입 등)에는 반드시 [국립해양조사원 바다누리](https://www.khoa.go.kr/)의 정확한 조석 예보를 확인하세요.

## 기술 스택 / 폴더 구조

**기술 스택**
- 프런트엔드: 바닐라 HTML / CSS / JavaScript (프레임워크·빌드 도구 없음)
- 실시간 DB: Firebase Realtime Database (모듈 SDK, CDN 로드)
- 외부 API: Open‑Meteo (fetch, 키 불필요)

**폴더 구조**
```
.
├─ index.html                 # 앱 전체 (HTML+CSS+JS 단일 파일)
├─ .nojekyll                  # GitHub Pages Jekyll 우회
├─ .github/workflows/pages.yml# GitHub Pages 자동 배포 워크플로
└─ README.md
```
